# hidraulica-subterranea

Biblioteca aberta (MIT) de **hidráulica de águas subterrâneas** em TypeScript: slug test (Hvorslev, Bouwer & Rice), ensaio de bombeamento (Theis, Cooper-Jacob, recuperação, Hantush-Jacob), velocidade de Darcy, fator de retardamento e tempo de trânsito.

```bash
npm install hidraulica-subterranea
```
